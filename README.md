# baki-protocol-ios

A native iOS habit tracker — the SwiftUI rewrite of
[baki-protocol](https://github.com/mohitshukla02/baki-protocol).

## Status

**Placeholder.** The repository is reserved and nothing has been committed yet.

The intent is to carry over what the web version already settled on: five habit
categories, a date carousel, streaks computed from the log, and local storage as
the source of truth with sync as an optional adapter rather than a dependency.
What a native build adds is the part the PWA can't do well — Home Screen
widgets, notifications, and HealthKit as an input.

Until there's code here, the [web version](https://github.com/mohitshukla02/baki-protocol)
is the working implementation.
